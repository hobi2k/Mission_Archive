# 미션 17 요약 보고서

## 1. 프로젝트 개요

- 팀/이름: 1팀 안호성
- 프로젝트명: 손글씨 숫자 인식 Streamlit 서비스
- 사용 모델: ONNX MNIST 모델
- 핵심 목표:
  - 사용자가 브라우저에서 숫자를 직접 그릴 수 있는 웹 인터페이스 제공
  - ONNX Runtime 기반 숫자 분류 추론 수행
  - 전처리 이미지, 예측 확률, 저장소 갤러리까지 한 화면에서 확인 가능하도록 구현

## 2. 서비스 구성

서비스는 아래 4개의 주요 영역으로 구성했다.

1. 입력 캔버스
- `streamlit-drawable-canvas`를 이용해 사용자가 마우스로 숫자를 직접 그릴 수 있도록 구현

2. 전처리 이미지 표시
- 사용자가 그린 이미지를 grayscale로 변환하고, 숫자 영역을 crop/pad/resize하여 MNIST 입력 사양인 28x28로 변환

3. 모델 추론 결과
- ONNX Runtime으로 추론을 수행하고, 0부터 9까지 각 숫자의 확률을 막대 차트로 시각화

4. 이미지 저장소
- 현재 손그림과 전처리 결과, 예측 숫자, 최대 확률을 로컬 저장소에 저장
- 저장된 결과를 Streamlit 화면 하단 갤러리에서 다시 확인 가능

추가로 상단 요약 카드와 우측 결과 패널 탭 구조를 적용해, 사용자가 입력과 결과를 한 화면에서 자연스럽게 읽을 수 있도록 레이아웃을 정리했다.

## 3. 코드 설명

### 3-1. 모델 관리

- `app.py`에서 앱 실행에 필요한 디렉터리를 준비하고, `models/mnist-8.onnx`가 없으면 GitHub ONNX 모델 저장소의 MNIST 모델을 자동 다운로드한다.
- `app.py`의 `load_onnx_session()`은 `st.cache_resource`를 사용해 ONNX Runtime 세션 생성을 캐싱하여 세션 간 재사용하도록 구성했다.

### 3-2. 이미지 전처리

- 캔버스 이미지는 검은 배경 + 흰색 선 기준으로 받는다.
- grayscale 변환 후 밝은 픽셀만 기준으로 bounding box를 찾는다.
- 숫자 영역을 crop한 뒤 정사각형 패딩을 주고 20x20으로 축소한 후, 28x28 검은 배경 중앙에 배치한다.
- 최종 입력은 `[1, 1, 28, 28]` shape의 `float32` 텐서로 변환한다.

### 3-3. 추론 및 시각화

- `onnxruntime.InferenceSession`으로 logits를 얻고 softmax를 적용해 확률 분포를 계산한다.
- 최고 확률 숫자를 `st.metric`으로 보여주고, 전체 확률은 `st.bar_chart`로 표시한다.

### 3-4. UI/스타일 구성

- `.streamlit/config.toml`에서 Streamlit 테마 색상과 기본 실행 옵션을 설정했다.
- `assets/style.css`에 카드형 레이아웃, 상단 요약 카드, metric 스타일, 갤러리 제목 스타일을 분리했다.
- `app.py`는 스타일 파일을 읽어와 화면에 주입하고, 입력 영역과 결과 영역을 가독성 중심으로 재배치했다.

### 3-5. 저장소 기능

- 저장 버튼을 누르면 원본 RGBA 이미지와 전처리 이미지가 `saved_images/` 아래에 저장된다.
- 메타데이터는 `gallery_index.json`에 누적 저장되며, 앱 하단에서 최신순으로 렌더링한다.

## 4. Docker 컨테이너화

### 4-1. Dockerfile

- 베이스 이미지: `python:3.11-slim`
- `requirements.txt`를 설치한 뒤 앱 소스 전체를 복사
- `streamlit run app.py --server.address=0.0.0.0 --server.port=8501`로 실행

### 4-2. 실행 명령

```bash
docker build -t mnist-onnx-streamlit:latest .
docker run --rm -p 8501:8501 mnist-onnx-streamlit:latest
```

## 5. Docker Hub URL

- `https://hub.docker.com/r/ahnhs2k/mnist-onnx-streamlit`

### 5-1. Docker Hub 배포 절차

```bash
docker login
docker tag mnist-onnx-streamlit:latest ahnhs2k/mnist-onnx-streamlit:latest
docker push ahnhs2k/mnist-onnx-streamlit:latest
```

- 로컬에서 빌드한 이미지를 Docker Hub 저장소 이름으로 다시 태깅한 뒤 업로드했다.
- 업로드 이후 Docker Hub 페이지에서 이미지 메타데이터와 pull 명령을 확인할 수 있다.

## 6. 결론

- Streamlit 웹 UI, ONNX 모델 자동 다운로드/캐싱, 전처리 시각화, 확률 차트, 저장소 갤러리까지 포함한 숫자 인식 서비스를 구현했다.
- 모델 구현에서 끝나는 것이 아니라, 사용자가 직접 입력하고 결과를 확인하는 서비스 형태까지 연결했다는 점에서 미션 목표를 충족했다.
